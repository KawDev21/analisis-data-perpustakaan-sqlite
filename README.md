Analisis Data Perpustakaan dengan SQLite

Proyek ini merupakan implementasi sistem basis data perpustakaan relasional menggunakan SQLite di Google Colab yang mencakup tabel buku, anggota, dan peminjaman.
* Pengelolaan Basis Data: Pembuatan struktur tabel relasional dengan kunci utama dan kunci asing serta pengisian data buku, anggota, dan transaksi peminjaman.
* Kueri Analitik SQL: Penggabungan data peminjaman menggunakan operasi JOIN serta perhitungan total buku yang dipinjam per anggota melalui GROUP BY dan fungsi agregasi.
* Eksplorasi dan Visualisasi: Pengolahan hasil kueri ke dalam DataFrame Pandas untuk menghitung durasi peminjaman dalam satuan hari serta pembuatan grafik distribusi menggunakan Matplotlib.
